# sound-catalog-php

Каталог звуковых файлов на PHP + MySQL (PDO). Пользователи загружают звуки, администратор модерирует: одобряет, управляет категориями, банит пользователей, рассматривает жалобы.

## Возможности

- Публичный каталог с поиском и фильтром по категории, встроенным аудиоплеером.
- Регистрация/вход с CAPTCHA-картинкой (генерируется на лету, `pages/captcha.php`).
- Загрузка звука (MP3/WAV, до 10 МБ) — тип файла проверяется по содержимому (`finfo`), а не по данным от браузера.
- Модерация: новый звук виден всем только после одобрения администратором.
- Жалобы на звуки, управление категориями и пользователями (бан/удаление) из админ-панели.

## Технологии

- PHP (без фреймворка), PDO + MySQL
- Bootstrap 5 (подключается по CDN)

## Настройка

1. Скопируйте [config.example.php](config.example.php) в `config.php` и впишите свои данные для подключения к MySQL:
   ```php
   return [
       'host' => 'localhost',
       'dbname' => 'sound_catalog',
       'username' => 'root',
       'password' => 'ваш_пароль',
   ];
   ```
   `config.php` в `.gitignore` — пароль от БД никогда не попадёт в репозиторий.
2. Откройте в браузере `pages/createdb.php` — создаст базу, таблицы и администратора (`admin` / `admin123`, смените после первого входа).
3. (Опционально) откройте `pages/initialValuesDb.php` — заполнит каталог тестовыми данными: несколько пользователей, категорий, звуков (уже лежат в `uploads/sounds/`) и жалоб.
4. Откройте `index.php` — каталог готов к работе.

## Структура

```
index.php                 публичный каталог
config.example.php        шаблон конфига подключения к БД (config.php не публикуется)
pages/classes.php         все классы: Database, Sound, User, SoundManager, UserManager, ComplaintManager
pages/login.php, register.php, logout.php
pages/captcha.php         генерация CAPTCHA-картинки
pages/upload.php          загрузка звука
pages/download.php        отдача файла по id (только одобренные)
pages/complaint.php       жалоба на звук
pages/admin.php           админ-панель
pages/createdb.php        создание схемы БД + администратор
pages/initialValuesDb.php заполнение тестовыми данными
uploads/sounds/           загруженные звуки (включая тестовые из initialValuesDb.php)
```

## Известные ограничения

- Нет защиты от CSRF на формах (вход, загрузка, действия в админ-панели) — для учебного проекта не критично, но в проде стоило бы добавить токены.
- После входа сессия не перегенерируется (`session_regenerate_id`) — минорная слабость.
